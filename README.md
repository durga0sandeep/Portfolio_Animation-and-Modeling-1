Project 1: Hierarchical Modeling and Animation

Implemented hierarchical 3D modeling and character animation using transformation hierarchies, rotation representations, and interpolation techniques. Explored quaternions, dual quaternions, and VQS transformations to create smooth and coordinated movements of articulated objects.


Project 2: Motion Along a Path

Developed 3D object movement along predefined curves using path-following and interpolation algorithms. Focused on arc-length parameterization, speed control, smooth orientation transitions, and techniques for generating consistent motion along curved trajectories.


Project 3: Inverse Kinematics

Explored and implemented inverse kinematics techniques to control articulated character movement and achieve target positions. Studied Jacobian-based solutions, cyclic coordinate descent (CCD), and constraint satisfaction for calculating joint configurations and realistic character poses.


Project 4: Physically-Based Modeling

Developed physically based simulation techniques using Newtonian mechanics and rigid-body dynamics. Explored mass and inertia, forces and torques, linear and angular momentum, collision detection, contact response, friction, and numerical integration to simulate realistic physical interactions.
